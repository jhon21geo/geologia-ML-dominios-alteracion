# Delimitación de Dominios Geológicos de Alteración Mediante Machine Learning, Geoquímica y Espectrometría

> **Autor:** Jhonatan Paul Mallma Espinoza  
> **Grado:** Tesis para optar el Título Profesional de Ingeniero Geólogo  
> **Institución:** Facultad de Ingeniería Geológica, Minera y Metalúrgica (FIGMM) - Universidad Nacional de Ingeniería (UNI)  

---

## 📌 Resumen Ejecutivo
Este repositorio contiene la replicación técnica y el marco conceptual de la tesis enfocada en la integración de datos de **espectrometría de reflectancia (SWIR)** y **geoquímica multielemental** mediante algoritmos de **Machine Learning** (clustering supervisado y no supervisado) para la caracterización y delimitación de dominios geológicos de alteración hidrotermal.

## 🛠️ Estructura del Proyecto

- `src/`: Módulos de Python para el procesamiento espectral y modelado de Machine Learning.
- `notebooks/`: Jupyter Notebooks interactivos con flujo paso a paso sobre datos anonimizados/sintéticos.
- `docs/`: Archivos fuente de la documentación y estructura de lectura.
- `data/`: Directorio para conjuntos de datos raw y procesados.

## 🚀 Inicio Rápido

1. **Clonar repositorio:**
   ```bash
   git clone https://github.com/jhonatanmallma/geologia-ml-dominios-alteracion.git
   cd geologia-ml-dominios-alteracion
   ```

2. **Instalar dependencias:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Ejecutar los notebooks:**
   ```bash
   jupyter notebook notebooks/
   ```
