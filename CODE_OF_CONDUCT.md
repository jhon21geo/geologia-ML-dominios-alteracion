# Código de conducta

Este proyecto adopta el [Contributor Covenant](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/) 2.1.

## Compromiso

Nos comprometemos a hacer de la participación en este proyecto una experiencia
libre de acoso para todas las personas, independientemente de edad, talla,
discapacidad visible o invisible, etnia, características sexuales, identidad y
expresión de género, nivel de experiencia, educación, estatus socioeconómico,
nacionalidad, apariencia, raza, casta, color, religión o orientación sexual.

## Estándares

Ejemplos de comportamiento que contribuyen a un ambiente positivo:

- Uso de lenguaje inclusivo y respetuoso.
- Respeto a puntos de vista y experiencias distintas.
- Crítica constructiva centrada en la metodología y el código.
- Aceptar la responsabilidad de los errores y aprender de ellos.

Comportamientos inaceptables: acoso, comentarios despectivos, ataques personales
o políticos, y publicación de información privada de terceros (incluyendo datos
de operaciones mineras no autorizados).

## Aplicación

Los reportes pueden enviarse abriendo un issue marcado como confidencial o
escribiendo a las personas mantenedoras del repositorio. Las infracciones pueden
conllevar advertencia, expulsión temporal o permanente de los espacios del
proyecto.
