# Introducción

!!! abstract "En esta página"
    Por qué el logueo visual ya no alcanza para contornear alteraciones, y qué
    pretende el flujo espectro + geoquímica + ML. El visor resume; no describe
    la unidad de calibración.

El avance de las geociencias en este siglo está ligado a transformar volúmenes
grandes de datos en conocimiento geológico **preciso y oportuno**. Durante
décadas, la alteración hidrotermal y los dominios se delimitaron con criterios
cualitativos y con el logueo visual. Esa base sigue siendo indispensable, pero
los sistemas minerales actuales exigen herramientas más objetivas y
reproducibles.

Este trabajo busca un puente entre la geología de alteración y la ciencia de
datos. El problema persistente en estimación de recursos es la
**incertidumbre de contornos** y las transiciones difusas entre dominios. Con
algoritmos de machine learning y el procesamiento sistemático de firmas
SWIR–VNIR y geoquímica, se propone un flujo cuantitativo de clasificación
mineralógica.

El valor no es solo la métrica del algoritmo: es entregar al geólogo un
**criterio técnico estandarizado** que reduzca sesgo interpretativo, fortalezca
el modelo de bloques y mejore la planificación.

!!! note "Alcance de esta versión en línea"
    El visor resume la tesis. No se detalla la logística ni la geometría de la
    unidad donde se calibró el método. El código público usa un yacimiento
    sintético con los mismos ensambles.
